Lemma P1' on finite multiset models (basis 1, sqrt2, sqrt3, sqrt5, sqrt7)
  (Q2) R = {1, 2} (relation 2*1-2), I = {sqrt3, sqrt5, sqrt7}: n_I = 3
    E_(a,b) for a+b <= 5: all zero
    all E >= 0: True; brute-force sequence count = E for a+b <= 4: True; (D) (all E < 1): True
    plain moments of G_R+G_I minus independent prediction, k = 3..5: ['6', '0', '460'] (positive: the R-relation is seen)
  (Q3) R = {1, sqrt2}, I = {1+sqrt2, sqrt3, sqrt5} (relation (1+sqrt2) - 1 - sqrt2): n_I = 3
    E_(a,b) for a+b <= 5: (2,1):4, (2,3):60, (4,1):48
    all E >= 0: True; brute-force sequence count = E for a+b <= 4: True; (D) (all E < 1): False
  (Q4) R = {1}, I = {sqrt2 (double), sqrt3, sqrt5}: n_I = 4
    E_(a,b) for a+b <= 4: (0,2):4, (0,4):156, (2,2):8
    all E >= 0: True; brute-force sequence count = E for a+b <= 4: True; (D) (all E < 1): False
    -> a double zero in the band violates (D) at (a,b) = (0,2): H_dec forces simple band zeros.
  (Q5) R = {1, 2}, I = empty: n_I = 0
    E_(a,b) for a+b <= 5: all zero
    all E >= 0: True; brute force not run; (D) (all E < 1): True
    -> with an empty band, (D) holds for every L: H_dec is vacuous (n_I = 0, mu_b(0) = 0 for b >= 1).
  (Q6) R = {1, sqrt2 [height > T*, weight 1/3]}, I = {1+sqrt2, sqrt3, sqrt5}: n_I = 3
    E_(a,b) for a+b <= 4: (2,1):4/3
    all E >= 0: True; brute-force sequence count = E for a+b <= 4: True; (D) (all E < 1): False
    -> the relation through the R-zero in (T*, T*+1] has weight 1/3 per sequence; (D) at (2,1) gives 4/3.
       Such relations may or may not be excluded by (D) (here they are); Theorem P7 uses only the
       exclusion of relations at heights <= T*, which Lemma P1' guarantees (weight exactly 1).
