# Integer weights and atoms of hull functions: what is proved

AI-produced (Anthropic's Claude), 2026-11-26. Labels as in `monotonicity/density/DENSITY.md`:
**Theorem / Proposition / Lemma / Corollary** = complete proof here; **Conjecture /
Heuristic** = not proved. Nothing here concerns Problem 12 of arXiv:2407.03530. The main
statement (`ν_{1/2}({0}) = 0` for `χ_{−4}` under GRH alone) is **not** proved here.

Main results. For integer weights, in two cases we prove that a level set of positive measure
can only occur at an odd integer level (so in particular there is no atom at `0`):
- Theorem 1.2: `w` is a finite measure, on any hull. By Proposition 1.4 (due to referee 1),
  such weights live on finitely many arithmetic progressions plus a finite set, so this is a
  statement about finite-dimensional tori. It never applies to the true race;
- Theorem 2.3: on the circle, the weights form a Toeplitz 0/1 sequence with one hole per
  period, located at `0` (any periods, any patterns; the exact class is defined in §2.2).
  This class contains the "Grandi" family of §2.1, which defeats the proof of Theorem 1.2.
  By Corollary 2.4, if the period ratios `q_k` are bounded or eventually prime, a level set
  of positive measure forces `m` to be periodic, and then lies at level `±1`. So for the
  non-periodic weights of this kind (period doubling, for instance) `F_M` has no atom at all,
  for any `M`.

The general toy question (arbitrary 0/1 weights on the circle) remains open (§§3–5).

## 0. Setting

`A` compact connected metrizable abelian group, `ι : ℝ → A` a continuous homomorphism with
dense image; the dual group is identified (via `e_g(ι(t)) = e^{igt}`) with a countable
subgroup `G ⊂ ℝ`; `D` is the generator of the flow `τ_s θ = θ ι(s)` (`D e_g = i g e_g`).
Weights `m : G∖{0} → [0,∞)`, symmetric, with `Σ_g m(g)²/(1+g²) < ∞`. For `M > 0`:

    F := 1 + Σ_{g≠0} m(g) (2M/(M+ig)) e_g ∈ L²(A),     w := 1/2 + Σ_{g≠0} m(g) e_g,     (D + M)F = 2M w .

The true race is the case `G` = group generated by the ordinates, `m(±γ) = m_γ` (positive
integers). The **toy** is `A = 𝕋`, `G = ℤ`, `m(n) = m_{|n|} ∈ {0,1}`.

## 1. Integer weights and bounded variation

**Lemma 1.1 (mod-2 lemma).** Let `G` be a subgroup of `ℝ` and let `L_1, …, L_r ⊂ G` be subgroups
`≠ {0}`; take `g_i ∈ G`, `n_i ∈ ℤ`, and a finitely supported `Q : G → ℤ`. If
`Σ_i n_i 1_{g_i+L_i} ≡ Q (mod 2)`, then `Q ≡ 0 (mod 2)`. In particular
`Σ_i n_i 1_{g_i+L_i} ≢ 1_{{0}} (mod 2)`.

*Proof.* (This form and proof are from referee 1, `REFEREE-1-TOY.md` O1. The first version
covered only `Q = 1_{{0}}`, by distinct subset sums.)
- For `ℓ ∈ G` put `(Δ_ℓ u)(x) := u(x+ℓ) − u(x)`, and pick `ℓ_i ∈ L_i∖{0}`.
- `Δ_{ℓ_i} 1_{g_i+L_i} = 0`, and the `Δ`'s commute and are `ℤ`-linear. So `Δ_{ℓ_1}⋯Δ_{ℓ_r}`
  annihilates the left side, and `Δ_{ℓ_1}⋯Δ_{ℓ_r} Q ≡ 0 (mod 2)`.
- Identify a finitely supported `u : G → 𝔽_2` with `Σ_x u(x)[x] ∈ 𝔽_2[G]`. Then `Δ_ℓ u` (mod 2)
  corresponds to `([−ℓ] + [0])·u`.
- `G ⊂ ℝ` is totally ordered, so `𝔽_2[G]` has no zero divisors: in a product of two nonzero
  elements, the coefficient at the sum of the two largest exponents is `1`.
- Each `[−ℓ_i] + [0]` is nonzero, so `Q ≡ 0 (mod 2)`. ∎

*Remark.* Torsion-freeness is essential. In `(ℤ/3)²` one has
`1_{{0}} ≡ 1_G + Σ_{4 lines through 0} 1_line (mod 2)` (referee 1, §1).

**Theorem 1.2 (integer weights, `w` a measure).** Assume the weights are integers and `w` is a
finite (complex Radon) measure on `A`; equivalently, the flow derivative of `F` is a measure.
Then:
- `2w = Pλ_A + σ`, where `σ ⊥ λ_A` and `P` is a trigonometric polynomial with integer
  coefficients;
- `P̂(0)` is odd, and `P̂(g)` is even for `g ≠ 0`.

If `F = c` on a set of positive Haar measure, then `P ≡ c`, and `c` is an odd integer. In
particular `λ_A(F = 0) = 0`. (By Proposition 1.4, these hypotheses force `F` to factor
through a finite-dimensional torus. They never hold for the true race.)

*Proof.* (i) *Structure of `2w`.* `2w` is a measure with integer Fourier–Stieltjes transform:
`1` at `0` and `2m(g)` elsewhere. Being bounded, the transform takes finitely many values `V`.
For `v ∈ V` the Lagrange polynomial `p_v`, taken in the convolution algebra, gives a measure
`p_v(2w)` with transform `1_{2ŵ = v}`; this is an idempotent. By Cohen's idempotent theorem
(Rudin, *Fourier analysis on groups*, §3.1; the theorem number was not re-checked), each level
set of `2ŵ` lies in the coset ring of `G`. Hence `2ŵ = Σ_i n_i 1_{g_i+L_i}` (a finite sum,
`n_i ∈ ℤ`). Indeed, let `𝓜` be the `ℤ`-span of the indicators of cosets. It is closed under
products, because two cosets meet in a coset or in `∅`. So the family `{S : 1_S ∈ 𝓜}`:
- contains the cosets;
- is closed under `∩`;
- is closed under `∪`, by `1_{A∪B} = 1_A + 1_B − 1_A1_B`;
- is closed under `∖`, by `1_{A∖B} = 1_A − 1_A1_B`.

It is therefore a ring of sets containing the cosets, so it contains the coset ring. Then
`2ŵ = Σ_{v∈V} v·1_{2ŵ=v}` has the stated form. (This argument is due to referee 3,
`REFEREE-3.md` §2.3.)

The measure with transform `1_{g+L}` is `e_g m_{L^⊥}`:
- for `L = {0}` it is `e_g λ_A`;
- for `L ≠ {0}`, `L^⊥` is a closed subgroup of infinite index (`A/L^⊥` is dual to the infinite
  group `L`), so `m_{L^⊥} ⊥ λ_A`.

Thus `2w = Pλ_A + σ`, with `σ̂ = Σ_{L_i≠0} n_i 1_{g_i+L_i}`. Since `2ŵ(0) = 1` and `2ŵ(g) = 2m(g)`
is even for `g ≠ 0`, we get `σ̂ = 2ŵ − P̂ ≡ 1_{{0}} − P̂ (mod 2)`. Lemma 1.1 with
`Q = 1_{{0}} − P̂` gives `P̂ ≡ 1_{{0}} (mod 2)`.

(ii) *Orbits.* Put `P̃ := M R_M P`, a trigonometric polynomial with `(D+M)P̃ = MP`, and
`h := F − P̃ ∈ L²`. `h` is real, because `2w` is a real measure and `R_M` preserves real
functions. Then `(D+M)h = Mσ`: the flow derivative of `h` is the finite measure
`μ := Mσ − Mhλ_A`, whose a.c. part is `−Mhλ_A` (as `σ ⊥ λ_A`). By Lemma 1.3, for a.e. `θ` the
function `t ↦ h(τ_tθ)` agrees a.e. with a locally BV function whose a.e. derivative is
`−Mh(τ_tθ)`. Let `F̃_θ` be the right-continuous representative of `t ↦ F(τ_tθ)`. It is
canonical, hence covariant (`F̃_{τ_rθ} = F̃_θ(·+r)`). It equals `F(τ_tθ)` for a.e. `t`. For a.e.
`t` it is differentiable, with derivative `(DP̃ − Mh)(τ_tθ) = M(P − F)(τ_tθ)`.

(iii) *Flat set.* Let `S := {F = c}`, with `λ_A(S) > 0`, and `Z_θ := {t : τ_tθ ∈ S}`. For a.e.
`θ` and a.e. `t ∈ Z_θ`:
- `t` is a Lebesgue density point of `Z_θ ∩ {F̃_θ = c}`;
- `F̃_θ(t) = c`, and `F̃_θ` is differentiable at `t`.

Approaching `t` through that set gives `F̃_θ'(t) = 0`, i.e. `(P − c)(τ_tθ) = 0`. By Fubini and
invariance of `λ_A`, `P = c` a.e. on `S`. So the trigonometric polynomial `P − c` vanishes on a
set of positive measure. By `DENSITY.md` Lemma 1.1 (whose proof applies to every `A` of §0),
all its coefficients vanish: `P ≡ c`. Then `c = P̂(0)`, which is odd by (i). ∎

**Lemma 1.3 (bounded variation along a flow).** Let `u ∈ L¹(A)` be real-valued. Suppose its
distributional flow derivative is a finite signed Radon measure `μ = ρλ_A + μ_s`, `μ_s ⊥ λ_A`.
(The derivative is `⟨Du, φ⟩ := −∫u Dφ dλ_A`, for `φ` trigonometric polynomials.) Then for a.e.
`θ`, `u_θ(t) := u(τ_tθ)` agrees a.e. with a function of locally bounded variation. That
function's a.e. derivative equals the density of the a.c. part of its derivative measure, and
it is `ρ(τ_tθ)` for a.e. `t`.

*Proof.* (a) *Bounded variation.* Fix a Borel representative of `u`. Let `φ_ε ≥ 0` be an even
mollifier supported in `[−ε,ε]`. Put `u_ε(θ) := ∫φ_ε(s) u(τ_{−s}θ) ds`, defined pointwise for
every `θ` with `u_θ ∈ L¹_loc`; this holds for a.e. `θ`.
- `Du_ε = ∫φ_ε'(s) u∘τ_{−s} ds ∈ L¹`. As distributions, `Du_ε = φ_ε⋆μ := ∫φ_ε(s)(τ_s)_*μ ds`
  (tested against trigonometric polynomials, which are dense in `C(A)`). Hence
  `‖Du_ε‖_{L¹} ≤ ‖μ‖`.
- `(u_ε)_θ = φ_ε * u_θ` is smooth, with derivative `(Du_ε)_θ`. By invariance of `λ_A`,
  `∫_A Var_{(−L,L)}((u_ε)_θ) dλ_A = 2L‖Du_ε‖_{L¹} ≤ 2L‖μ‖`.
- As `ε → 0`, `φ_ε * u_θ → u_θ` in `L¹_loc`. The variation is lower semicontinuous (it is a
  supremum of `L¹_loc`-continuous functionals over a countable family). With Fatou this gives
  `∫_A Var_{(−L,L)}(u_θ) dλ_A ≤ 2L‖μ‖` for `L ∈ ℕ`.

So `u_θ` is locally BV on a flow-invariant set `A_0` of full measure; let `ν_θ := ∂_t u_θ`. Since
`u_{τ_rθ} = u_θ(·+r)` exactly, `ν_{τ_rθ} = ν_θ(·+r)` for `θ ∈ A_0`, `r ∈ ℝ`. Also
`θ ↦ ∫g dν_θ = −∫g'(t)u(τ_tθ)dt` is measurable for `g ∈ C¹_c(ℝ)`.

(b) *Disintegration.* For `ψ ∈ C_c(ℝ)` and `f ∈ C(A)`,

    ∫_A ∫ ψ(t) f(τ_tθ) dν_θ(t) dλ_A(θ) = (∫ψ) ∫_A f dμ .                        (1.1)

For `u_ε` in place of `u`, this is invariance of `λ_A` plus `Du_ε = φ_ε⋆μ`. Now let `ε → 0`.
- On the left, `∂_t(u_ε)_θ dt = φ_ε * ν_θ → ν_θ` vaguely for each `θ ∈ A_0`. The integrand is
  dominated by `‖ψ‖_∞‖f‖_∞ |ν_θ|(supp ψ + [−1,1])`, which is integrable by (a).
- On the right, `∫f d(φ_ε⋆μ) = ∫φ_ε(s)∫f∘τ_s dμ ds → ∫f dμ` by uniform continuity of `f`.

Extension to bounded Borel `f` (monotone class): let `𝓒` be the class of bounded Borel `f` for
which `θ ↦ ∫ψ(t)f(τ_tθ)dν_θ(t)` is measurable and (1.1) holds.
- `𝓒` contains `C(A)` and is a vector space.
- `𝓒` is closed under bounded pointwise limits, by dominated convergence: in `t` because
  `|ν_θ|(supp ψ) < ∞`, and in `θ` by the bound in (a).

So `𝓒` contains all bounded Borel functions.

(c) *Densities.* Write `ϑ` for points of `A_0`. Put `ρ̃(ϑ) := limsup_{δ→0, δ∈ℚ} ν_ϑ((−δ,δ))/2δ`,
with `ρ̃ := 0` where this is infinite and off `A_0`. Let
`Z := {ϑ ∈ A_0 : limsup_{δ→0} |ν_ϑ|((−δ,δ))/2δ = ∞}`.

Covariance gives `ν_θ((t−δ,t+δ)) = ν_{τ_tθ}((−δ,δ))`. So, by Lebesgue's differentiation theorem,
for `θ ∈ A_0`:
- `ρ̃(τ_tθ)` is the density of the a.c. part of `ν_θ` at a.e. `t`;
- the singular part of `ν_θ` is carried by the Lebesgue-null set `{t : τ_tθ ∈ Z}`.

By Fubini `λ_A(Z) = 0`. Also `ρ̃ ∈ L¹(λ_A)`: its integral is bounded by the integral of
`|ν_θ|([0,1])`.

Take `ψ ≥ 0` with `∫ψ = 1` in (1.1), and split `f = f1_{A∖Z} + f1_Z`. By invariance the first
part gives `∫ f ρ̃ dλ_A`, and the second is a measure carried by `Z`. So
`μ = ρ̃λ_A + (a measure carried by the null set Z)`. Uniqueness of the Lebesgue decomposition
gives `ρ̃ = ρ` `λ_A`-a.e. By Fubini, the a.c. density of `ν_θ`, which is `ρ̃(τ_tθ)`, equals
`ρ(τ_tθ)` for a.e. `t`, for a.e. `θ`. ∎ (The Euclidean analogue is the slicing theorem for BV
functions.)

**Proposition 1.4 (structure under the hypotheses of Theorem 1.2; referee 1, O2).** Assume
integer weights, and that `w` is a finite measure. Then `2ŵ = b + Σ_i n_i 1_{g_i+ℤℓ_i}`, with `b`
finitely supported and finitely many `ℓ_i ≠ 0`. Consequently:
- (a) `m` is bounded and supported in finitely many arithmetic progressions plus a finite set.
  `F` factors through a finite-dimensional torus, with a linear flow.
- (b) For the true race, `w` is **not** a finite measure on the hull.

*Proof.* Cohen gives `2ŵ = Σ n_i 1_{g_i+L_i}` (proof of Theorem 1.2). A subgroup of `ℝ` is cyclic
or dense. Let `D` be the sum of the terms with dense `L_i`.

`supp D` is locally finite:
- `m` is integer-valued and `Σ m²/(1+g²) < ∞`, so
  `#{g ∈ supp m : |g| ≤ T} ≤ (1+T²)Σ m²/(1+g²)`;
- cosets of cyclic groups are locally finite;
- `supp D ⊂ supp(2ŵ) ∪ ⋃_{cyclic}(g_i+L_i)`.

Suppose `D ≠ 0`, and pick a point `x ∈ supp D` with no other point of `supp D` within `δ`.
Choose `ℓ_i ∈ L_i∖{0}` for the dense `L_i`, from the largest index down, with
`|ℓ_{i+1}| > Σ_{j≤i}|ℓ_j|` and `Σ|ℓ_i| < δ`; a dense subgroup meets every interval. Then the
subset sums `ℓ_T` are distinct and nonzero for `T ≠ ∅`. So
`0 = (Π_iΔ_{ℓ_i}D)(x) = Σ_T ±D(x + ℓ_T) = ±D(x)`, a contradiction. Hence `D = 0`, which gives
(a).

For (b): `Σ_{0<γ≤T} m_γ = N(T,χ) ~ (T/2π) log T` by Riemann–von Mangoldt, whereas (a) forces
`O(T)`. ∎

*Remarks.*
- (1) Theorem 1.2 is complementary to `DENSITY.md` Remark 7.5, not an extension of it.
  - Remark 7.5 (a sketch) treats arcs, with integer weights `O(n^k)`, via Pólya–Carlson.
  - Theorem 1.2 treats sets of positive measure, but only weights for which `w` is a measure.
    On the circle these are the weights for which `n ↦ m_{|n|}` is periodic off a finite set
    (Helson).
- (2) By Proposition 1.4(b), Theorem 1.2 says nothing about the true race. It also says
  nothing about the real-weight models of `DENSITY.md` §7, for the simpler reason that their
  weights are not integers.
- (3) Where integrality enters:
  - `2ŵ ≡ 1_{{0}} (mod 2)`: the weights are integers, and `ŵ(0) = 1/2` is the half-integer of
    Chebyshev's bias;
  - Lemma 1.1 transfers this congruence to the a.c. part `P` of `2w`, whose constant term is
    therefore odd;
  - flatness forces `F` to equal that constant term.

## 2. Beyond bounded variation: the Grandi mechanism and Toeplitz weights

### 2.1 The Grandi mechanism

**Proposition 2.1 (period doubling).** Let `ε_n = 1` if the 2-adic valuation of `n ≥ 1` is odd,
`0` otherwise, and `F_M` the toy function with these weights. Then `ŵ(2n) = 1 − ŵ(n)` for all
`n ∈ ℤ` (including `n = 0`, `ŵ(0) = 1/2`), `ŵ(odd) = 0`, hence (with `δ̂_0(n) = 1/2π`)
`w(t) + w(2t) = π(δ_0 + δ_π)` and

    F_M(t) + F_{M/2}(2t) = Q_M(t),      Q_M := 2πM (R_M δ_0 + R_M δ_π),
    F_M = 1 + Σ_{k≥0} (−1)^k (Q_{M/2^k}(2^k t) − 2)       (uniformly convergent).

*Proof.* The coefficient identity is `ν_2(2n) = ν_2(n) + 1`. Apply `2M R_M` and use
`R_M[u(2·)](t) = (1/2)(R_{M/2}u)(2t)`. Iterating, `F_M(t) = Σ_{k<K}(−1)^k Q_{M/2^k}(2^kt) +
(−1)^K F_{M/2^K}(2^Kt)` in `L²`. Now `‖F_{M'}(2^K·) − 1‖_2 = ‖F_{M'} − 1‖_2 ≤ 2√2 M'(Σn^{−2})^{1/2}`
(normalised `L²`), and `2πM' R_{M'}δ_0 = 2πM' e^{−M't}/(1 − e^{−2πM'})` on `(0,2π)`, so
`Q_{M'} − 2 = O(M')` uniformly. Hence the alternating series converges uniformly, the
remainder combines with `2Σ_{k<K}(−1)^k` into the constant `1` in `L²`, and the expansion holds
a.e. (in particular `F_M` is bounded). ∎

Here `w` is not a measure (Helson: `n ↦ ε_{|n|}` is not periodic off a finite set). `F_M` jumps
at every dyadic point:
- by `4πM/3` at `0` and at `π`;
- by `±(4πM/3)2^{−a}` at each of the `2^a` points `πj/2^a` (`j` odd, `a ≥ 1`).

So its total variation is infinite. (These values follow from the closed form of §2.2; the
jump at `0` was checked numerically by referee 1.)

**Heuristic (why Theorem 1.2 does not extend directly).** Abel-summed, the termwise drift
`−M Σ(−1)^k Q_k`, a Grandi series, is `−M F_M`. The half-integer `ŵ(0) = 1/2` is then carried
by conditionally convergent atoms at the dyadic points, and the proof of Theorem 1.2 has
nothing to act on. That proof needs an a.c. part of `2w` that is an integer trigonometric
polynomial with odd constant term.

The true race carries its bias the same way on the special orbit:
`(D+M)E^θ_M = 2M Σ_p χ*(p)(log p)p^{−1/2}δ_{log p}` has no drift. The drift `M` that `ŵ(0) = 1/2`
requires is produced by the prime atoms. Their positive mean density comes from the prime
squares through the explicit formula (the difference between `θ`- and `ψ`-type sums).

*What is proved:* Theorem 1.2 never applies to the true race (Proposition 1.4(b)). For Toeplitz
weights with one hole per period, located at `0` (the class of §2.2), the parity law of
Theorem 1.2 holds, by a different argument (Theorem 2.3). Corollary 2.4 shows that the Grandi
mechanism does not by itself create atoms. For the weights of Proposition 2.1, and for every
valuation family `v_k = c_k·1_{≠0}` with `(c_k)` not eventually constant (equivalently, `m` not
periodic), `F_M` has no atom at all, for every `M > 0`.

### 2.2 Toeplitz weights with one hole per period at `0` obey the same parity law

*Setting.* Integers `q_k ≥ 2` (`k ≥ 1`), `P_0 := 1`, `P_k := q_1⋯q_k`; patterns
`v_k : ℤ/q_k → {0,1}` with `v_k(0) = 0`. For `n ≥ 1` put `k(n) := max{j : P_j | n}` and

    m_n := v_{k(n)+1}( n/P_{k(n)} mod q_{k(n)+1} ).

Equivalently: for some chain `P_k | P_{k+1}` (`P_{k+1}/P_k ≥ 2`), the one-sided sequence
`(m_n)_{n≥1}` is `P_k`-periodic off `P_kℤ` for every `k` (one hole per period at each level,
located at the residue `0`). Indeed, for `P_k ∤ n` we have `k(n) < k`, and both `k(n)` and
`m_n` depend only on `n mod P_k`. Conversely, given such a sequence, put `v_{k+1}(r) := m_{P_k r'}` for any `r' ≥ 1`
with `r' ≡ r ≢ 0 (mod q_{k+1})`. This is well defined by `P_{k+1}`-periodicity off `P_{k+1}ℤ`,
and it reproduces `m`.

This is a **proper** subclass of the regular Toeplitz sequences whose only non-periodic
position is `0`. For example, `m_n := 1` iff `ν_2(n) + ν_3(n)` is odd is such a sequence, but
it is `P`-periodic off `Pℤ` for no `P ≥ 2` (referee 2, `REFEREE-2.md` T2). For non-symmetric
patterns only the one-sided sequence has this structure: the toy weights `n ↦ m_{|n|}` on `ℤ`
are then `P_k`-periodic off `P_kℤ` only on each half-line.

Examples: the *valuation family* `v_k = c_k·1_{≠0}`
(`c_k ∈ {0,1}`; with `q_k = 2`, `c_k = 1_{k even}` it is the period-doubling sequence of
Proposition 2.1); Toeplitz sequences with arbitrarily fast-growing periods `q_k` and
arbitrary patterns (the "locally periodic" constructions of §5 when they are hierarchical);
every periodic sequence (period `Q ≥ 2`: take `q_1 = Q`, `q_k = 2` and `v_k(1) = m_Q` for
`k ≥ 2`). Put `V_k(e) := Σ_{r mod q_k} v_k(r) e^{2πire/q_k}`, an algebraic integer of `ℚ(ζ_{q_k})`.

**Theorem 2.3.** For such `m` and every `M > 0`: if `λ{F_M = κ} > 0`, then every `v_k` is
symmetric (`v_k(−r) = v_k(r)`) and `κ` is an odd integer. In particular `F_M` has no atom at `0`.
The same holds, with the same proof, for patterns `v_k : ℤ/q_k → ℤ_{≥0}` (`v_k(0) = 0`) such
that `Σ_n m_n²/(1+n²) < ∞` (Remark (4)).

*Proof.* Fix `i`, put `P := P_{i+1}`, `q := q_{i+1}`, `ε := 2πM/P`, and split `m = m' + m''`, where
`m'` is `m` with the entries in `Pℤ` replaced by `0`; correspondingly `F = F' + F''` (`F'` the
function of `m'`, `F''` the series over `n ∈ Pℤ∖{0}`). Sub-arcs: `J_s := [2πs/P, 2π(s+1)/P)`,
`t = 2π(s+u)/P`, `u ∈ [0,1)`.

(i) *Periodic part.* Let `p` be the `P`-periodic extension of `(m'_n)_{n≥1}` (`p(0) = 0`) and
`p_a(r) := (p(r) − p(−r))/2`; `p_a ≡ 0` iff `v_1, …, v_{i+1}` are symmetric. Here and below,
sums over `r` run over the representatives `r = 1, …, P−1`. Both formulas below come from
`Σ_{r=1}^{P−1}` and depend on this choice. The distribution `w' = 1/2 + 2Re Σ_{n≥1} p(n)e^{int}` is the limit in `D'(𝕋)`
of its Abel means, since the coefficients are bounded. Moreover
`Σ_{n≥1} p(n)z^n = Σ_{r=1}^{P−1} p(r)z^r/(1−z^P)` is rational with poles only at the `P`-th
roots of unity, so off `(2π/P)ℤ` the Abel means converge locally uniformly. With
`1/(1−e^{iθ}) = (1 + i cot(θ/2))/2` (`θ ∉ 2πℤ`) this gives, on each open sub-arc,

    w' = 1/2 + Σ_r p(r) sin((P/2−r)t)/sin(Pt/2) = 1/2 + Im[ e^{iπu} Σ_r p_a(r) e^{−2πir(s+u)/P} ] / sin(πu),

a real-analytic function. (In the second form, `t = 2π(s+u)/P`; the factors `(−1)^s` from
`e^{iπ(s+u)}` and `sin(π(s+u))` cancel, and the terms `r`, `P−r` of the symmetric part of `p`
cancel.) On each open sub-arc, `F' = 2MR_Mw'` solves the ODE `(D+M)F' = 2Mw'` with a
real-analytic right side, so it is real-analytic there. (If `p_a ≢ 0`, `w'` may have
singularities of order `1/u` at the ends of the sub-arcs, and `F'` logarithmic ones; only
`F' ∈ L²` is used.) If
`p_a ≡ 0`, `n ↦ m'_{|n|}` is `P`-periodic on `ℤ`, so `w'` is `1/2` plus an atomic measure
carried by `(2π/P)ℤ`. The atom at `τ = 2πs/P` has mass `(2π/P)Σ_{r mod P} p(r)e^{2πirs/P}`.
Split `r` according to `k(r) = k−1` (`k ≤ i+1`): level `k` contributes only when `(P/P_k) | s`.
Hence for `q ∤ s` the mass is `(2π/P)V_{i+1}(s mod q)`. The periodic Green's function
`R_Mδ_0 = e^{−Mt}/(1−e^{−2πM})` jumps by `1`, so from `(D+M)F' = 2Mw'`:

    F' = 1 + 2B(s) e^{−εu}  on J_s   (constants B(s)),
    B(s) = B(s−1)e^{−ε} + ε V_{i+1}(s mod q)     whenever q ∤ s.                    (R)

(ii) *Remainder.* `F''` has its frequencies in `Pℤ`, so it is `2π/P`-periodic:
`Φ(u) := F''(2π(s+u)/P)` does not depend on `s`; and
`∫_0^1|Φ|² du = Σ_{n∈Pℤ∖0} m_{|n|}·4M²/(M²+n²) ≤ (4π²/3) M²/P²`.

(iii) *Density.* Suppose `λ(E) > 0`, `E := {F = κ}`. The arcs `[2πa/P_i, 2π(a+1)/P_i)` form
refining partitions with mesh `→ 0`, so (martingale convergence) for a.e. `t ∈ E` and all
large `i` the level-`i` arc `I ∋ t` has `λ(E∩I) ≥ 0.99λ(I)`. Fix such `i` and `I`; it is the
union of the `q` sub-arcs `J_s`, `s = aq, …, aq+q−1`, and by Markov's inequality at most
`⌊0.1q⌋` of them are *bad* (`λ(E∩J_s) < 0.9λ(J_s)`). On a good sub-arc,
`F'(2π(s+u)/P) + Φ(u) = κ` for `u` in a set `U_s` of measure `≥ 0.9`. For good `s, s'`, the
set `U_s ∩ U_{s'}` has measure `≥ 0.8`. There the two real-analytic functions
`u ↦ F'(2π(s+u)/P)` and `u ↦ F'(2π(s'+u)/P)` agree, hence they agree on all of `(0,1)`.
Applying `D + M`, so do the two restrictions of `w'`.

*Symmetry.* Some pair `s−1, s` (with `aq < s < aq+q`) consists of two good sub-arcs, since
`2⌊0.1q⌋ < q − 1`. Put `A_r := p_a(r)e^{−2πirs/P}(1 − e^{2πir/P})` and `ω_r := π(1−2r/P)`
(`r = 1, …, P−1`, so that `ω_{P−r} = −ω_r`). By the second form of `w'`,
`w'_{s−1}(u) − w'_s(u) = −Im[Σ_r A_r e^{iω_r u}]/sin(πu)`, where `w'_s(u) := w'(2π(s+u)/P)`.
So equality of `w'` on `J_{s−1}` and `J_s` reads `Im Σ_r A_r e^{iω_r u} = 0` on `(0,1)`, i.e.
`Σ_r (A_r − \bar A_{P−r}) e^{iω_r u} = 0`. The `ω_r` are distinct, so linear independence of
exponentials gives `A_r = \bar A_{P−r}`. Since `p_a` is odd, `\bar A_{P−r} = −A_r`, so `A_r = 0`
and `p_a ≡ 0`. As `i` can be taken arbitrarily large, every `v_k` is symmetric, and (R) is
available.

On good sub-arcs the identity is now `1 + 2B(s)e^{−εu} + Φ(u) = κ` on `U_s`, so
`B(s) = B(s') =: B_*` for good `s, s'`. If `s−1` and `s` are both good (and `q ∤ s`), (R) gives
`V_{i+1}(s mod q) = β_* := B_*(1−e^{−ε})/ε`. Each bad sub-arc spoils at most two values of
`e = s mod q`, so `V_{i+1}(e) = β_*` for at least `(q−1) − 2⌊0.1q⌋ ≥ 0.6(q−1)` of the
`e ∈ {1,…,q−1}`.

(iv) *Galois.* `(ℤ/q)^×` acts on `{1,…,q−1}` by multiplication, and
`V_{i+1}(ae) = σ_a(V_{i+1}(e))` with `σ_a(ζ_q) = ζ_q^a`. On an orbit `O`, for a value `β` taken
there, the proportion of `e ∈ O` with `V_{i+1}(e) = β` is `|Gal(ℚ(ζ_q)/ℚ(β))|/|Gal(ℚ(ζ_q)/ℚ)|
= 1/[ℚ(β):ℚ]` (the map `a ↦ ae_0` onto `O` has fibres of equal size). Some orbit has at least
`60%` of its points in `{V_{i+1} = β_*}`, so `[ℚ(β_*):ℚ] = 1`: `β_*` is a rational algebraic
integer, `β_* = n ∈ ℤ`.

(v) *Parity.* Now `2B_*e^{−εu} = 2nρ(u)` with `ρ(u) := εe^{−εu}/(1−e^{−ε}) ∈ [1−ε, 1+ε]`
(`ε ≤ 1`), and `Φ = κ − 1 − 2nρ` on `U_s` for good `s`. If `κ` is not an odd integer, let
`d := dist(1−κ, 2ℤ) > 0`. For `|n| ≤ d/(8ε)`, `|κ−1−2nρ| ≥ d − 2|n|ε ≥ d/2`; for `|n| > d/(8ε)`,
`|κ−1−2nρ| ≥ 2|n|(1−ε) − |κ−1| ≥ d/2` once `ε ≤ ε_0(κ)`. So `λ{u : |Φ(u)| ≥ d/2} ≥ 0.9`, which
contradicts (ii) as soon as `(4π²/3)M²/P² < 0.9d²/4`, i.e. for `i` large. ∎

*Remarks.*
- (1) The proof uses two features of Toeplitz weights. At every level the remainder is
  *exactly* periodic at the scale of the sub-arcs, so it cannot tell the sub-arcs apart. And
  the jumps are algebraic integers permuted by Galois. Integrality enters in (iv)–(v) in the
  same way as in Theorem 1.2: an integer `n` against the half-integer `ŵ(0) = 1/2` (the
  target `1` of the drift).
- (2) Identities (R), the periodicity in (ii) and the bound in (ii) are checked numerically
  to machine precision in `toy_toeplitz2.py` (`toy_toeplitz2_results.txt`). The closed form
  used there is compared with partial Fourier sums in `toy_toeplitz.py`
  (`toy_toeplitz_results.txt`). That comparison has error `~1e−4`, the error of the partial
  sums; it does not decrease from `N = 2e5` to `4e5`. An exact check: referee 3 compared the
  closed form with an independent radial-integral evaluation, with agreement `2.3e−15`
  (`referee3/r3_toeplitz_forms.py` (E)).
  - Referee 2 reproduced these independently, from direct smoothed Fourier sums
    (`referee2/r2_subarcs.py`; 12 cases, agreement `≤ 2.5e−11`). This covers both forms of
    `w'`, the exponential form of `F'`, (R), the atom masses, the difference formula of the
    symmetry step, and the periodicity and bound of (ii).
  - The Galois step was checked in exact arithmetic: for `q ≤ 30` by referee 2
    (`referee2/r2_galois.py`), and on 124,522 patterns, with 0 violations, by referee 3
    (`referee3/r3_galois.py`).
- (3) Not covered:
  - one hole per period not located at `0`, e.g. `P_1 = 2`, `q_k = 3` (`k ≥ 2`) and hole
    class `h_k + P_kℤ` with `h_k = P_k/2`. The level-`k` remainder then has its frequencies in
    `h_k + P_kℤ`, so it is antiperiodic: `F''(t + 2π/P) = −F''(t)`. Referee 2 sketches an
    argument for this case (`REFEREE-2.md` O4); it is not checked here;
  - holes in several classes, e.g. `m_n = [ν_2(n)+ν_3(n) odd]`, whose level-`k` holes are
    `2^kℤ ∪ 3^kℤ`. The remainder is then a sum `Σ_h e^{iht}Φ_h(t)` over the hole classes, whose
    phases differ between sub-arcs (here: a `2π/2^k`-periodic plus a `2π/3^k`-periodic
    function), so step (iii) cannot compare adjacent sub-arcs;
  - all non-hierarchical sequences (Sturmian, concatenations of periodic blocks, generic
    sequences).
- (4) *Integer patterns.* Let `v_k : ℤ/q_k → ℤ_{≥0}` with `Σ_n m_n²/(1+n²) < ∞`. Then the
  proof goes through verbatim, with one change: the bound in (ii) becomes
  `∫_0^1|Φ|² ≤ 8M² Σ_{n≥P} m_n²/(M²+n²)`, which still tends to `0` as `i → ∞` (a tail of a
  convergent series). Steps (iv)–(v) use only that the `v_k` are integers and that
  `∫|Φ|² → 0`.

**Corollary 2.4 (no atoms for bounded or prime period ratios).** Let `m` be as in Theorem 2.3, with
0/1 patterns. Assume that for every large `k` one of the following holds:
- (a) `q_k ≤ Q`, for a fixed `Q`;
- (b) `q_k` is prime;
- (c) `v_k` is constant on `(ℤ/q_k)∖{0}`.

If `λ{F_M = κ} > 0` for some `M > 0`, then `κ ∈ {1, −1}` and `v_k = ((1−κ)/2)·1_{≠0}` for all
large `k`. Consequently `m` is periodic, and `κ = 1 − 2m_P` for every period `P` of `m`.

In particular the law of `F_M` has no atoms, for every `M > 0`, in two cases:
- the period-doubling weights of Proposition 2.1;
- more generally, every valuation family `v_k = c_k·1_{≠0}` with `(c_k)` not eventually
  constant (any `q_k`, by (c)).

*Proof.* Let `E := {F = κ}` with `λ(E) > 0`. By martingale convergence, as in (iii), there is
`t ∈ E` with `λ(E∩I)/λ(I) → 1` along the level-`i` arcs `I = I_i(t)`. By Theorem 2.3 every
`v_k` is symmetric, so (R) holds at every level. Fix a large `i` such that `q := q_{i+1}`
satisfies (a), (b) or (c), and use `P, ε, Φ, J_s, U_s, B(s), B_*, β_*` as in the proof of
Theorem 2.3, for this `I`.

*Step 1: `V_{i+1}(e) = β_*` for every `e ∈ {1, …, q−1}`.*
- Case (a). For large `i`, `λ(I∖E) ≤ λ(I)/(4Q)`. Every sub-arc has `λ(J_s) = λ(I)/q ≥ λ(I)/Q`,
  so `λ(J_s∖E) ≤ λ(J_s)/4`. Hence each `U_s` has measure `≥ 3/4`, and any two of them meet in
  a set of measure `≥ 1/2`. As in (iii), `B(s) = B_*` for **all** `q` sub-arcs of `I`. Then
  (R) at `s = aq+1, …, aq+q−1` gives `V_{i+1}(e) = β_* = B_*(1−e^{−ε})/ε` for every `e ≠ 0`.
- Case (b). By (iii)–(iv), `V_{i+1}(e_0) = β_* ∈ ℤ` for some `e_0 ≠ 0`. As `q` is prime, every
  `e ∈ {1,…,q−1}` is `ae_0` with `a ∈ (ℤ/q)^×`, and `V_{i+1}(ae_0) = σ_a(β_*) = β_*`.
- Case (c). If `v_{i+1} = c·1_{≠0}`, then `V_{i+1}(e) = c Σ_{r≢0} ζ_q^{re} = −c` for every
  `e ≠ 0`. By (iii), `V_{i+1}(e) = β_*` for at least one `e ≠ 0`, so `β_* = −c`.

In every case there is a sub-arc `J_s` with `B(s) = B_*` and `λ(U_s) ≥ 3/4` (in cases (b), (c)
a good one).

*Step 2: `v_{i+1} = −β_*·1_{≠0}`, so `β_* ∈ {0, −1}`.* Since `v_{i+1}(0) = 0`,
`Σ_{e mod q} V_{i+1}(e) = q·v_{i+1}(0) = 0`, so `V_{i+1}(0) = −(q−1)β_*`. For `r ≢ 0`, Fourier
inversion gives `v_{i+1}(r) = q^{−1}Σ_e V_{i+1}(e)ζ_q^{−re} = q^{−1}(V_{i+1}(0) − β_*) = −β_*`.
As `v_{i+1}` takes values in `{0,1}`, `β_* ∈ {0, −1}`.

*Step 3: a bound.* On `U_s` (Step 1), `Φ(u) = κ − 1 − 2β_*ρ(u)` with `ρ(u) ∈ [1−ε, 1+ε]` as in
(v). Since `|β_*| ≤ 1`, `|Φ(u)| ≥ |κ−1−2β_*| − 2ε` on a set of measure `≥ 3/4`. By (ii),
`(3/4)·(|κ−1−2β_*| − 2ε)_+² ≤ (4π²/3)M²/P²`.

*Step 4: the level.* Write `β_*^{(i)}` for the value at level `i`. Step 3 holds for every
large `i`, and `ε = 2πM/P_{i+1} → 0`, so `|κ − 1 − 2β_*^{(i)}| → 0`. As `β_*^{(i)} ∈ {0, −1}`,
it follows that `κ ∈ {1, −1}` and `β_*^{(i)} = (κ−1)/2` for all `i ≥ i_1`, say. By Step 2,
`v_k = ((1−κ)/2)·1_{≠0}` for all `k > i_1`.

*Step 5: periodicity.* Put `P' := P_{i_1}`.
- For `n ≥ 1` with `P' | n` we have `k(n) ≥ i_1`. So
  `m_n = v_{k(n)+1}(n/P_{k(n)} mod q_{k(n)+1}) = (1−κ)/2`, since the argument is `≢ 0`.
- For `P' ∤ n` we have `m_{n+P'} = m_n`, by `P'`-periodicity off `P'ℤ`.

Hence `m_{n+P'} = m_n` for all `n ≥ 1`, and `κ = 1 − 2m_{P'}`. If `P` is any period of `m`,
then `m_P = m_{PP'} = m_{P'}`.

For the last assertion, Step 4 shows that `c_k = (1−κ)/2` for all large `k`. ∎

*Remarks on Corollary 2.4.*
- (1) The periodic case does occur. For most periodic symmetric patterns, `F_M` is flat at
  level `1 − 2m_Q` on some sub-arcs for special values of `M`.
  - *Formula* (referee 3). With minimal period `Q`, `W(s) := Σ_{r mod Q}p(r)cos(2πrs/Q)` and
    `f_s(x) := Σ_{j<Q}x^jW(s−j)`, `F_M` is flat on the sub-arc `J_s` iff `f_s` has a root
    `x = e^{−2πM/Q} ∈ (0,1)`. The level is then `1 − 2m_Q`.
  - *Counts.* Among the 11,956 primitive symmetric patterns with `2 ≤ Q ≤ 22`, 11,878 have a
    flat sub-arc for some `M > 0`. The other 78 have none, e.g. `m_n = 1_{n odd}` (`f_s = ±(1−x)`)
    and both primitive patterns with `Q = 3`.
  - Counting distinct `M`, with exact double roots once, there are 108,164 (pattern, sub-arc,
    `M`) triples, all at levels `±1` (`referee3/r3_periodic_flat.py`, validated in 60-digit
    arithmetic by `r3_periodic_flat_hpcheck.py`). Referee 2's figure 108,205
    (`referee2/r2_periodic_flat.py`) used a different root count.
  - Non-symmetric periodic patterns give no flat piece, as Theorem 2.3 requires.
- (2) Without (a)–(c), the same argument proves a weaker statement. At a density point `t` of
  `E`, the proportion of `e ∈ {1, …, q_{i+1}−1}` with `V_{i+1}(e) = (κ−1)/2` tends to `1` as
  `i → ∞`. *Proof.*
  - The number of bad sub-arcs of `I` is `< 10q·λ(I∖E)/λ(I) = o(q)`, so
    `V_{i+1}(e) = β_*` for a proportion `→ 1` of the `e`.
  - By (iv), `β_* = n ∈ ℤ`. By Theorem 2.3, `κ − 1 = 2n_0` with `n_0 ∈ ℤ`.
  - Suppose `n ≠ n_0`. If `|n| ≤ 1/(2ε)`, then `|n_0 − nρ| ≥ |n_0 − n| − |n|ε ≥ 1/2`. If
    `|n| > 1/(2ε)`, then `|n_0 − nρ| ≥ (1−ε)/(2ε) − |n_0| ≥ 1/2` once `ε` is small.
  - So `|Φ| = 2|n_0 − nρ| ≥ 1` on `U_s`, which contradicts (ii) for large `i`.
- (3) *Open* (`REFEREE-2.md` O3): can `|κ| ≥ 3` occur when the `q_k` are unbounded and
  composite? The arithmetic of step (iv) allows it.
  - For `v = 1_{(ℤ/q)^×}`, `V(e) = c_q(e)` (a Ramanujan sum), which equals `μ(q)` on the
    units.
  - For `q = 21` this is `1` on 12 of the 20 values (referee 2, T10). At `q = 20` some
    symmetric 0/1 pattern has `V = −2` on 12 of the 19 nonzero residues, so at a single level
    the arithmetic allows `κ = −3` (referee 3, `r3_galois.py`).
  - For `q` a product of two large distinct primes, `μ(q) = 1` and the units have proportion
    close to `1`.

## 3. The toy question: two reformulations

**Proposition 3.1 (compactness).** Fix `M > 0` and a finite set `W ⊂ ℤ_{≥0}` of allowed weights.
Let `τ*_η(N) := min_{m ∈ W^N} (η-quantile of |F_{m,N}| on 𝕋)` (`F_{m,N}` the polynomial with
weights `m_1..m_N`; nonincreasing in `N` when `0 ∈ W`). If `τ*_η(N) → 0` as `N → ∞`, some
`m ∈ W^ℕ` has `λ{F_m = 0} ≥ 2πη`; conversely, if some `m` has `λ{F_m = 0} ≥ 2πη`, then
`τ*_{η'}(N) → 0` for every `η' < η`. Equivalently: no weight sequence has an atom at `0` iff
`lim_{τ→0} sup_{m∈W^ℕ} λ{|F_m| ≤ τ} = 0` (a uniform small-ball bound).

*Proof.* (⇒ of the first claim) Take `m^{(j)}` (finite, extended by `0`) with
`λ{|F_{m^{(j)}}| ≤ τ_j} ≥ 2πη`, `τ_j → 0`,
and a coordinatewise limit `m^∞` along a subsequence (`W^ℕ` is compact). For fixed `K`,
`‖F_{m^{(j)}} − F_{m^∞}‖_2² ≤ 2Σ_{n≤K}|m^{(j)}_n − m^∞_n|²|a_n|² + 2(max W)²Σ_{n>K}|a_n|²`, and the
first term vanishes for `j` large; letting `K → ∞`, `F_{m^{(j)}} → F_{m^∞}` in `L²`. So the laws
converge weakly and,
for each fixed `τ`, `λ{|F_∞| ≤ τ} ≥ limsup_j λ{|F_{m^{(j)}}| ≤ τ} ≥ 2πη` (portmanteau, closed
set). Let `τ → 0`. (Converse) Truncate `m` at `N` and use Chebyshev on the tail:
`{|F_{m,N}| ≤ τ} ⊇ {F_m = 0} ∖ {|F_m − F_{m,N}| > τ}`, so
`λ{|F_{m,N}| ≤ τ} ≥ 2πη − 2π‖F_m − F_{m,N}‖_2²/τ²` (normalised `L²`), which exceeds `2πη'` for
`N` large. The last sentence: if
`s(τ) := sup_m λ{|F_m| ≤ τ}` stays `≥ s_0 > 0`, the same compactness argument (with infinite
sequences, coordinatewise convergence giving `L²` convergence by dominated convergence) yields
`m^∞` with `λ{F_{m^∞} = 0} ≥ s_0/2`; the other direction is trivial. ∎

**Proposition 3.2 (an `M`-free necessary condition).** If `F_M = 0` a.e. on `S` for some `M > 0`
and 0/1 weights `m`, write `η_n = 2m_n − 1 ∈ {±1}`. Then
`B_η(t) := Σ_{n≥1} η_n sin(nt)/n` coincides a.e. on `S` with an absolutely continuous function
whose derivative vanishes a.e. on `S`.

*Proof.* `Ψ := t/2 + 2Σ m_n sin(nt)/n` is a primitive of `w`, and so is `F/(2M) + I/2` with
`I(t) = ∫_0^t F` (differentiate, using `(D+M)F = 2Mw`); hence they differ by a constant. On `S`,
`Ψ = I/2 + C` with `I` absolutely continuous and `I' = F = 0` a.e. on `S`. Since
`2Σ m_n sin(nt)/n = Σ sin(nt)/n + B_η = (π−t)/2 + B_η` on `(0,2π)`, `B_η = Ψ − π/2` there. ∎

So the toy (any `M`) would be settled negatively by: *a ±1 series `Σ η_n sin(nt)/n` is never
"relatively flat" on a set of positive measure*.

For periodic `η` with period `q` the derivative is explicit. Off the `q`-th roots of unity,
`B_η' = −η_q/2 + Σ_{1≤r<q/2}(η_r − η_{q−r}) sin((q/2−r)t)/(2sin(qt/2))` (referee 1, §7).
- If `η_r = η_{q−r}` for all `r` (equivalently, `w` is a measure), `B_η` is piecewise affine with
  slope `−η_q/2 = ±1/2`.
- Otherwise `B_η` has logarithmic singularities. Example: `η = (1,−1,−1)` repeated gives
  `B_η' = 1/2 + 1/(1+2cos t)`.

Every ±1 sequence has the same quadratic variation
`∫|B_η(t+h) − B_η(t)|² dt/2π = πh/2 − h²/4` (`0 ≤ h ≤ 2π`). But its QV measure can be singular
(atomic for symmetric periodic `η`), so this alone gives nothing.

## 4. Where the right-limit method stops (Breuer–Simon)

`F = 0` on `S` ⟺ `g = Σ m_n (2M/(M+in)) z^n` has the pseudocontinuation
`−\overline{g(1/\bar z)} − 1` across `S`. Breuer–Simon (Adv. Math. 226 (2011), Thms 1.3, 1.4, 5.1)
prove for **arcs**: right limits of bounded coefficients are reflectionless, and finitely valued
coefficients are eventually periodic. For a set `S` of positive measure the shifted, rescaled
functions `N z^{−N}(g − P_N)` have bounded coefficients but `H²` norm `≍ √N` (when the ones of `m`
have positive density near `N`), and vanishing on `S`
is not preserved under the resulting weak limits. The spectral analogue (Remling, Ann. Math.
2011) uses Herglotz value distributions; no Herglotz structure was found here. Not settled.

For `η ≥ 0.25` the values have stopped moving (plateau); for `η ≤ 0.15` they are still

`[0,1]` reach `≈ 2e-4` at `N = 256` (`η = 0.15`). With weights in `{0,1,2}`:
`η log₂(1/τ*) ≈ 1.07, 1.17, 1.12` at `η = .40, .35, .30` (lower floor, as an entropy count
predicts, but not by the full factor `log₂ 3`).

**Heuristic (entropy count).** `2^N` weight sequences; making `|F_N| ≤ τ` on a fraction `η` of
`≍ N` effectively independent sample points costs `≈ ηN log₂(1/τ)` bits; feasibility needs
`η log₂(1/τ) ≲ log₂|W|`. This is a count over "typical" sequences, not a proof (structured
sequences can do better), but it matches the plateaus for `0.2 ≤ η ≤ 0.3`.

**Conjecture 5.1.** Fix `M > 0` and a finite set `W ⊂ ℤ_{≥0}` of allowed weights. Then for
every `m ∈ W^ℕ` the toy function satisfies `λ{F_m = 0} = 0`. Moreover, if `|W| ≥ 2`,
`sup_m λ{|F_m| ≤ τ}/2π ≤ C_M log|W| / log(1/τ)` for small `τ`. (Referee 1 notes that
`|W| = 1` and the dependence on `M` must be excluded from any two-sided form: for
`W = {1}` there is a single function with a simple zero. Also `‖F_M − 1‖_2² ≤ 8ζ(2)(max W)²M²`
uniformly in `m`, so the left side tends to `0` as `M → 0`.)

Proved instances: Theorem 1.2 (when `w` is a measure) and Theorem 2.3 (Toeplitz weights with
one hole per period at `0`, any periods and patterns, symmetric or not) give the first part of
the conjecture for these two classes, indeed with "odd levels only". For the non-periodic
weights of Corollary 2.4 (bounded or eventually prime period ratios, or valuation families)
there is no atom at any level. Evidence against overconfidence: the beam optimisers are
structured (only even indices, long blocks with period 4 in `n`). A "ghost" mechanism
(locally periodic blocks emulate real weights away from the points `2πj/Q`, with a porous
zero set avoiding them) is excluded by Theorem 2.3 when the blocks are organised
hierarchically with one hole per period at `0` (the class of §2.2). It is not excluded for
the other Toeplitz hierarchies of Remark (3) after Theorem 2.3, nor for non-hierarchical
concatenations of periodic blocks, and it could beat the entropy count there.
