## 1. A finite-index criterion

**Proposition 1.1.** Let `H ⊂ G` be a subgroup of finite index `N` such that `Λ := Γ ∖ H` is
finite. Then `ν_M({c}) ≤ 1/N` for every `M > 0` and every `c ∈ ℝ`.

*Proof.* Let `K := H^⊥ = {θ ∈ A : e_h(θ) = 1 for all h ∈ H}`.
- By (I2) and Pontryagin duality, `K` is a closed subgroup of `A` isomorphic to the dual of
  `G/H`, so `|K| = N`.
- The functions `k ↦ e_g(k)` on `K` (`g ∈ G`) separate the points of `K`, since the
  characters of `A` separate its points. Each depends only on `g + H`, since `e_h ≡ 1` on `K`
  for `h ∈ H`.
- `G = H + ⟨Λ⟩`, because `Γ ⊂ H ∪ Λ` generates `G`.
- Hence for `k ≠ k'` in `K` there is `γ ∈ Λ` with `e_γ(k) ≠ e_γ(k')`.

Write `F_M = F_H + F_Λ` with `F_Λ := Re Σ_{γ∈Λ} m_γ r_γ e_γ`, a trigonometric polynomial. The
Fourier coefficients of `F_H` sit on `{0} ∪ ±(Γ∩H) ⊂ H`. For `k ∈ K` the translate `F_H(·k)` has
Fourier coefficients `F̂_H(g)e_g(k) = F̂_H(g)`, so `F_H(·k) = F_H` a.e. Hence
`F̃_H(θ) := N^{−1}Σ_{k∈K} F_H(θk)` equals `F_H` a.e. and satisfies `F̃_H(θk) = F̃_H(θ)` for all
`k ∈ K` and **all** `θ`. Replace `F_H` by `F̃_H`. This changes `F_M` only on a null set, so it
does not change `ν_M`.

Let `E := {F_M = c}` and `S(θ) := {k ∈ K : θk ∈ E}`. By invariance of `λ_A`,
`∫_A |S(θ)| dλ_A(θ) = Σ_{k∈K} λ_A(Ek^{−1}) = N·ν_M({c})`.

Now take `k ≠ k'`, both in `S(θ)`. Then `F_Λ(θk) = c − F_H(θ) = F_Λ(θk')`, so `θ` is a zero of
`D_{k,k'}(θ) := F_Λ(θk) − F_Λ(θk') = Re Σ_{γ∈Λ} m_γ r_γ (e_γ(k) − e_γ(k')) e_γ(θ)`. This is a
trigonometric polynomial in the pairwise distinct characters `e_{±γ}`, `γ ∈ Λ`, and at least
one of its coefficients is nonzero (`m_γ r_γ ≠ 0`). By Lemma 1.1 of `DENSITY.md` its zero set
is null. There are finitely many pairs, so `|S(θ)| ≤ 1` for a.e. `θ`, and
`N·ν_M({c}) ≤ 1`. ∎

**Lemma 1.2.** Let `Λ ⊂ Γ` be finite. Then `G/⟨Γ∖Λ⟩` is finite unless hypothesis TS of
`DENSITY.md` §3 holds (some ordinate is not in the `ℚ`-span of the ordinates above some
height).

*Proof.* If TS fails, `⟨Γ∖Λ⟩_ℚ ⊃ ⟨Γ_{>T}⟩_ℚ = ⟨Γ⟩_ℚ` for `T ≥ max Λ`. So every `λ ∈ Λ` has a
positive multiple in `⟨Γ∖Λ⟩`. Then `G/⟨Γ∖Λ⟩` is generated by the finitely many images of
`Λ`, each of finite order, so it is finite. ∎

**Hypothesis TS_ℤ ("the tail does not generate").** `[G : ⟨Γ_{>T}⟩] → ∞` as `T → ∞` (the
index counts as `∞` when it is infinite). The index is nondecreasing in `T`, so this is the
same as being unbounded.

**Theorem 1.3 (GRH + NCZ + TS_ℤ).** For every `M > 0` the measure `ν_M` has no atoms.
Consequently, for every `m > −1/2`:
- the logarithmic densities of `{D_m > 0}`, `{D_m ≥ 0}` and `{x : D_m(x) > c·x^M/log x}`
  exist (every `c`);
- near-ties have logarithmic density `0`.

The proof of the consequences is that of `DENSITY.md` Theorems 2.1(d) and 3.4. In particular,
for `χ_{−4}`, under GRH + TS_ℤ the logarithmic density of `{x : π(x;4,3) > π(x;4,1)}` exists.

*Proof.* There are two cases.
- If `[G : ⟨Γ_{>T}⟩] = ∞` for some `T`, then Lemma 1.2 (with `Λ = Γ_T`) shows that TS holds,
  and `DENSITY.md` Theorem 3.1 gives absolute continuity.
- Otherwise `H_T := ⟨Γ_{>T}⟩` has finite index `N_T → ∞`, and `Γ ∖ H_T ⊂ Γ_T` is finite.
  Proposition 1.1 gives `ν_M({c}) ≤ 1/N_T` for every `T`. ∎

**Corollary 1.4 (what an atom forces; strengthens the atom case of `DENSITY.md` Corollary
3.2).** Assume GRH +
NCZ and `ν_M({c}) = α > 0` for some `M > 0`, `c ∈ ℝ`. Then:
- there is `T_0` with `⟨Γ_{>T}⟩ = ⟨Γ_{>T_0}⟩ =: H_∞` for all `T ≥ T_0`;
- `[G : H_∞] ≤ 1/α`;
- for every `T`, each ordinate `γ` has a multiple `nγ` with `1 ≤ n ≤ 1/α` that is an
  **integer** linear combination of ordinates exceeding `T`.

*Proof.* By `DENSITY.md` Theorem 3.1, TS fails. By Lemma 1.2 all the indices `[G : ⟨Γ_{>T}⟩]`
are finite, and by Proposition 1.1 they are at most `1/α`. A nondecreasing bounded integer
sequence is eventually constant, and nested subgroups of equal finite index are equal. The
order of `γ` in `G/H_∞` divides `|G/H_∞| ≤ 1/α`, and `⟨Γ_{>T}⟩ ⊃ H_∞` for every `T`. ∎

*Remark.* In the atom case, `DENSITY.md` Corollary 3.2 says only that each ordinate is a
**rational** combination of high ordinates, with an unspecified denominator. (Corollary 3.2
also covers laws without atoms that are not absolutely continuous; Corollary 1.4 does not.) Corollary 1.4 bounds the
denominator by `1/α`, uniformly. With the certified bound on the possible atom at `0` of the
classical race (`< 0.0891`, `DENSITY.md` Theorem 5.4), this does not yet give a contradiction.
An atom at `0` of mass `α` makes `G/H_∞` a finite group of order `≤ 1/α`. It does not force
`G/H_∞` to be trivial.

## 2. Comparison with the other hypotheses

1. **TS implies TS_ℤ.** A nonzero `ℚ`-linear form vanishing on `Γ_{>T}` makes the index
   infinite.
2. **TS_ℤ is strictly weaker than TS.** For an abstract frequency set
   `X = {2^k α : k ≥ 0}`, `α > 0` (no claim that ordinates look like this), we have
   `⟨X_{>T}⟩ = 2^{k(T)} ℤα`. The index is `2^{k(T)} → ∞`, but `⟨X_{>T}⟩_ℚ = ℚα`, so TS fails.
3. **TS_ℤ is incomparable with FD** (`DENSITY.md` §3).
   - The set `X` above fails FD. Every homomorphism `G_T = ℤα → ℤ` that is nonzero is
     nonzero on all of `X_T`, and `#X_T → ∞`.
   - The set of `DENSITY.md` Example 3.3a satisfies Devin's Theorem 5.4(1) hypothesis, hence
     FD. But it fails TS_ℤ: there `b_n = (b_n + b_{N(n,j)}) − b_{N(n,j)}` with both terms above
     any height, so `⟨X_{>T}⟩ = G` for all `T`.
4. **The disjunction "TS_ℤ or FD".** It implies continuity of `ν_M` (Theorem 1.3 here,
   Theorem 3.4 there).
   - The following hypotheses that `LITERATURE.md` lists for continuity of the law or for
     existence of the density imply FD, and so imply the disjunction:
     - Devin's Theorems 2.2 and 5.4(1)–(4);
     - Devin 1909.03975, Corollary 2;
     - Bailleul's Theorem 1.7;
     - Martin–Ng's Theorems 1.5(a) and 1.7(a);
     - LI.

     Two caveats (referee 3, `REFEREE-3.md` §2.4):
     - Hypotheses stated for several `L`-functions (Martin–Ng, Bailleul, Devin 1909.03975)
       are read for the union of the ordinates. FD, TS and TS_ℤ are defined in `DENSITY.md`
       for a single real `χ`.
     - Martin–Ng Theorem 1.7(a) concerns the zeros of `ζ` and the race `π(x)` versus `li(x)`.
       FD for those ordinates makes sense as a condition on a set of frequencies. But
       Theorem 1.3 here and `DENSITY.md` Theorem 3.4 are proved only for the races `D_m` of a
       real primitive `χ`, so they do not apply to that race as proved.

     `LITERATURE.md` also mentions Akbary–Ng–Shahabi 1306.1657, "continuity only under LI-type
     hypotheses", without stating them. That item is not covered by the claim.
   - **Exception: Devin's parity hypothesis.** `LITERATURE.md` also lists the hypothesis of
     Devin's Theorem 2.3, `Σk_γγ = 0 ⇒ Σk_γ ≡ 0 (mod 2)`. It is a hypothesis for symmetry, not
     continuity, and it implies neither FD nor TS_ℤ. Take the abstract frequency set
     `X = {(2k+1)α : k ≥ 0}` (`REFEREE-2.md` H9):
     - the relation lattice has the basis `e_k − (2k+1)e_0` (`k ≥ 1`), whose coordinate sums
       `−2k` are even, so the parity hypothesis holds;
     - `G_T = ℤα`, so FD fails, as in item 3;
     - two consecutive odd numbers generate `ℤ`, so `⟨X_{>T}⟩ = ℤα = G` and TS_ℤ fails.
   - `LITERATURE.md` also lists results that assume GRH only (Hayani; Kaczorowski–Ramaré, not
     read). GRH is not known to imply FD.
   - The disjunction is strictly weaker than FD (by item 3).
   - The hypotheses that imply TS also imply TS_ℤ by itself. These are Devin's Theorems 2.2
     and 5.4(2)–(4), Devin 1909.03975 Corollary 2, Bailleul's Theorem 1.7, and Martin–Ng's
     self-sufficient zeros.
5. **Proof mechanism.** The proof of Theorem 3.1 in `DENSITY.md` moves along a one-parameter
   subgroup on which the tail is invariant. Proposition 1.1 moves along a *finite* subgroup.
   The finite-subgroup version sees integer relations that the `ℚ`-linear argument cannot
   see. It is the hull analogue of step (iii) of `TOY.md` Theorem 2.3. In both, the remainder
   is invariant under a finite group of translations, so on each orbit the level set is
   governed by the non-invariant part. The two mechanisms differ:
   - In Proposition 1.1 the non-invariant part separates the points of each orbit. This is
     proved from `G = H + ⟨Λ⟩`, not from the remainder, and it bounds the level set by one
     point per orbit.
   - In `TOY.md` step (iii) the invariant remainder forces the non-invariant parts to
     *coincide* on good translates.

*Status of the hypotheses.* None of TS, TS_ℤ, FD is known for any `L`-function. Like the
others, TS_ℤ is implied by LI. `LITERATURE.md` searched only for `ℚ`-span conditions; no
search for finite-index conditions ("the subgroup generated by the large ordinates") has been
made, so TS_ℤ is not claimed to be new.
