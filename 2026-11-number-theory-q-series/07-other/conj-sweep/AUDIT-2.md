## A. R07 — CRIM (arXiv:2606.16828)

### A1. Encoding against the source
Checked in `arXiv.tex`:
* Moves (Section 3, first paragraph): a row move removes the `i`-th part for any `1 ≤ i ≤ r`; a
  column move is a row move on the conjugate. Normal play: "a player who reaches a terminal position
  loses" (terminal = no move = `[ ]`), consistent with the source's `[2,1], [2,2] ∈ 𝒫`, rows/columns
  `∈ 𝒩`. Rank `= |r − λ_1|` (Section 2.1). `conj:main` reads verbatim "Every 𝒫-position is of even
  rank."
* Boundary word: `E^{λ_r} N E^{λ_{r−1}−λ_r} N ⋯ E^{λ_1−λ_2} N` has `r` letters `N` and `λ_1` letters `E`,
  so rank `≡ |w| (mod 2)`. Removing row `i` deletes its `N`; removing column `j` deletes the `j`-th `E`;
  rows that became empty are leading `N`'s, columns that became empty are trailing `E`'s. Verified
  mechanically (`audit2/crim_extra.py`, part (a)): for all 914 partitions of `1 ≤ n ≤ 16` the set of
  options obtained by literally deleting a row/column of the cell set and re-attaching equals the
  set `{canon(w − one letter)}`; i.e. every legal move is a single-letter deletion and every
  single-letter deletion is a legal move.
* Meld `μ ⋄ λ = [μ_1+λ_1,…,μ_1+λ_m, μ_1,…,μ_k]` ⇒ `w(μ⋄λ) = w(μ)w(λ)` (checked on samples incl. the
  identity `(μ⋄λ)' = λ'⋄μ'`).
* Thick hook `Γ^{a,b}_{r,c} = [c^a, b^{r−a}]`, `r > a ≥ 2`, `c > b ≥ 2` (source, Section 2.2): word
  `E^b N^{r−a} E^{c−b} N^a` (asserted in my code for all 10 626 thick hooks with `r+c ≤ 26`). Source
  Theorem `thm:thick-hook`: Grundy value 0 iff `r ≡ c (mod 2)` — as used in R07.
* Hook `Γ_{r,c} = [c, 1^{r−1}]`; source Proposition `lem:hook`: value `(r+c) mod 2 + 1 ≥ 1` if
  `min(r,c) = 1`, `0` if same parity, `3` otherwise; hence losing iff `r, c ≥ 2` and `r ≡ c (mod 2)` — as
  used in R07.
* Stack (source, paragraph "Stacking partitions"): for `d = d(λ)` the Durfee length, `λ ◁ μ` is
  defined iff `λ_{d+i} = d` (`1 ≤ i ≤ k`) and `λ_d ≥ d + μ_1`, and equals
  `[λ_1,…,λ_d, λ_{d+1}+μ_1,…,λ_{d+k}+μ_k, λ_{d+k+1},…,λ_r]`. In `conj:bloby` the hook is the FIRST
  argument (`λ* = Γ_{r,c} ◁ λ`). For a hook `d = 1`, so the stack is defined iff `k ≤ r−1` and
  `λ_1 ≤ c−1`, and `Γ_{r,c} ◁ λ = [c, 1+λ_1,…,1+λ_k, 1^{r−1−k}]`, with word
  `E N^{r−1−k} w(λ) E^{c−1−λ_1} N`. I implemented the literal definition and compared word and
  definedness with R07's formula on 1440 pairs (hooks with `r, c ≤ 8`, all `λ` of `n ≤ 8`): no
  discrepancy (`audit2/crim_cor.py`).
* `conj:pself` verbatim: "A parity self-conjugate partition is in 𝒩 if and only if it is the stack of
  odd self-conjugate hooks and [1]." With the literal stack definition I generated all such stacks
  with rows+columns `≤ 26` (64 partitions, including `[1]` itself) and found exactly the words
  generated by `EN`, `w ↦ E N^a w E^a N` (`a` odd `≥ 1`) — R07's description is correct (inner stack is
  self-conjugate with an odd number of rows, so `a = b = r − 1 − k` is odd). Left- and right-nested
  stacks agree on the tested triples.

### A2. Logic of the proof of Theorem 1
Complete. Points examined:
* `B(v) ⇔ B(canon(v))` for ALL words needs exactly (i) `δ(0,N) = 0` (leading `N`'s) and (ii)
  `acc(δ(q,E)) = acc(q)` for all 17 states (trailing `E`'s). Both verified from the printed table (also
  by hand). This covers deletions that produce non-canonical words and words with `canon = ε`
  (e.g. from `EN`, from a single row or a single column).
* (iv) is needed only for nonempty canonical `w`; these are exactly the words reached from `E` whose
  last letter is `N`. The configuration update `q ↦ δ(q,x)`, `T ↦ δ(T,x) ∪ {q}` is correct (the new
  one-letter deletions of `wx` are the old ones followed by `x`, plus `w` itself); the start
  configuration for `w = E` is `(δ(0,E), {0})`.
* Induction: options of a nonempty canonical `w` are shorter canonical words; base case `ε` (losing,
  accepted). Nothing is missing.
* Parity: the product of `B` with the parity bit has 16 reachable pairs; no accepting state is
  entered by an `N`-step at odd length. (Accepting states at odd length do occur for
  non-canonical words such as `E`, which is why the restriction to words ending in `N` matters.)

## B. R06 — 3-sumfree sequences (arXiv:2609.16843)

### B1. Printed statement and definitions
`main.tex`, Conjecture `conj:except`: "For every `d ≥ 3` the 3-sumfree sequence `S_{1,d−1,2d−1}` is
ultimately periodic, and, with the exception of `d = 3` or `d = 5`, the preperiod length is `d+3`
and the period length is `d` modulo `8d−1`." Confirmed verbatim, including "`8d−1`" and "`d = 3` or
`d = 5`". Definitions (Introduction): `m` = minimal period length of the characteristic sequence
`C`, `k` = number of 1s in the minimal preperiod of `C`, `p` = number of 1s in one period; "Whenever we
mention 'the (pre)period length' … we refer to the minimal values"; sequences are greedy and strict
(sums of 3 *different* previous entries). R06 quotes these correctly.

### B2. Proof of the Theorem (`d ≥ 6`, `m = 8d−3`) — line by line
* Reduction "(I)+(II) ⇒ `S = T`": correct (membership of `x > 2d−1` depends only on `S ∩ [1, x)`;
  summands of a 3-sum of positive integers are automatically `< x`); seeds need `d ≥ 3`.
* (I), `x ∈ [2d, 3d−2]` and `x = 4d−1`: correct.
* (I), `x ∈ B_j`: residues `a = 1`, `b = d−1`, `e = 4d−1`, `U = [2d−2, 3d−2]` with residue `3d−2`
  attained only by the element `3d−2`; `σ < 2m` holds (`σ ≤ 10d−5 < 16d−6`). The eight types are all
  subsets of `{a, b, e}` completed by `U`-elements. Ranges recomputed by hand and by brute force over
  distinct elements for `d ≤ 14` (`audit2/sumfree3_intervals.py`): `UUU [6d−6, 9d−6]`, `aUU [4d−3, 6d−3]`,
  `bUU [5d−5, 7d−5]`, `eUU [8d−5, 10d−6]` (the distinctness remark is needed and correct: without it
  the maximum would be `10d−5`, the first forbidden value), `abU [3d−2, 4d−2]` (tight: `3d−2` is one
  above the target interval), `aeU [6d−2, 7d−2]`, `beU [7d−4, 8d−4]`, `abe 5d−1`. None meets
  `[2d−2, 3d−3] ∪ [10d−5, 11d−6]` for any `2 ≤ d ≤ 150` (and by the formulas for all `d ≥ 2`).
* (II): two-sums of `C` fill `[4d−1, 6d−5]`, three-sums `[6d, 9d−9]` (set equality checked for
  `3 ≤ d ≤ 150`). `[3d−1, 4d−2]`: correct. `[4d, 10d−6]`: the four families are
  `[4d, 6d−4]`, `[5d−2, 7d−6]`, `[6d, 9d−9]`, `[8d−2, 10d−6]`; they cover iff `d ≥ 6` (the binding
  inequality is `8d−2 ≤ 9d−8`), confirmed as sets: covering holds for all `6 ≤ d ≤ 150` and fails for
  `d ≤ 5`. Gaps: `ρ + s_1 + s_2` gives `[3d−2, 4d−3]`, `[4d−2, 6d−4]`, `[5d−4, 7d−6]`, `[6d−3, 9d−8]`,
  `[8d−4, 10d−6]`, union `[3d−2, 10d−6]` for `d ≥ 3` (checked as sets); `β` exceeds and differs from
  `s_1, s_2`, all summands `< x`. The list of cases exhausts the complement of `T` above `2d−1`.
* Consequence "(preperiod, period, modulus) `= (d+3, d, 8d−3)`": correct under the source's (minimal)
  definitions. **G-R06-1 (R06, sentence "Hence … ultimately periodic modulo `8d−3` with preperiod
  length `d+3` and period length `d`")**: minimality is not argued. One line suffices: the periodic
  part of `C` is `1^d 0^{7d−3}`, whose least period is `8d−3`; `4d−1 ∈ S` but `4d−1+m = 12d−4 ∉ S`
  (`11d−6 < 12d−4 < 18d−8`), so the preperiod has exactly `d+3` ones; equivalently `D_{d+3} = 6d−4 ≠
  7d−2 = D_{2d+3}`.

**Verdict: PROOF COMPLETE.**

### B4. The counterexample to the printed conjecture — CONFIRMED

* Other readings. (a) Any other parametrisation inside the family `S_{f,g,g+d}`: an exhaustive scan
  of all triples with `4 ≤ d ≤ 12`, `f < g ≤ 2d+2` finds NO triple with `(k,p,m) = (d+3, d, 8d−1)`;

  and period length …"), and even then `d = 4` remains a counterexample (`p = 3`, with periodicity
  proved as in B3).
