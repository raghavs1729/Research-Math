# AI-assisted results in number theory and q-series (November 2026)

**This work was produced by AI (Anthropic's Claude models), directed by Raghav Sharma.**
Proofs, code, computations and literature searches were generated by AI. Every result
listed as proved below was read by at least one independent AI referee told to find errors,
working with its own code. **No human expert has refereed any of it yet.** Novelty searches were
careful but not exhaustive. Corrections are very welcome: raghavsharma1729@gmail.com.

Companion to the earlier project on weighted prime races:
paper [doi:10.5281/zenodo.21947101](https://doi.org/10.5281/zenodo.21947101), code
[github.com/raghavs1729/weighted-prime-races](https://github.com/raghavs1729/weighted-prime-races).

## What is machine-checked in Lean

Everything under `lean/` builds with `lake build` and uses only Lean's three standard axioms (propext, Classical.choice, Quot.sound): no `sorry`, no `native_decide`. Each project has a Mathlib-only statement file, a script that prints the axioms, and a script comparing the statement file with the proved file. Lean guarantees the proofs; what a reader should check is that each statement file says what the printed conjecture says.

|---|---|
| `lean/lean-krtw` | Kanade–Russell–Tsuchioka–Warnaar identity (i), every k |
| `lean/lean-nahm` | Andrews–Gordon identities; E8 Nahm-sum identity and companions; E7 identity |
| `lean/lean-tau` | x²² − 3x¹¹y² + y⁴ ∉ {461, −599} over the integers |
